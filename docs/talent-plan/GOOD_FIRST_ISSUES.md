# Good First Issues — 维护指南

公开入口请以 [`.github/GOOD_FIRST_ISSUES.md`](../../.github/GOOD_FIRST_ISSUES.md) 为准，避免出现两份任务清单。

## 创建方式

1. 打开仓库的 [New Issue](https://github.com/kngwyc3/Agent-Learning-Hub/issues/new/choose) 页面。
2. 选择 **Good First Issue** 模板。
3. 填写清晰的 `Goal`、`Scope` 和验收标准。
4. 添加 `good first issue` 与 `help wanted` 标签。

## 每周运营节奏

- 从 backlog 中挑 2–3 个小任务创建 issue。
- 优先选择文档、smoke test、eval case、移动端样式这类低风险任务。
- 有 PR 合并后，在 README Contributors 区致谢贡献者。
