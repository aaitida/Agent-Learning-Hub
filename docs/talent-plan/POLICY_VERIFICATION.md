## 已查到的官方背景（供参考，以细则为准）

1. **认定办法**（2026-01-01 施行，有效期 5 年）：创新贡献类含「知名代码、模型平台达到一定贡献」，**细则由市人社局分批发布**（成熟一批公布一批）。
2. **申请时限**：首次在深缴纳社保之日起 **1 年内** 通过 i深圳 提交。
3. **审核周期**：区人社部门受理后 **10 个工作日** 出审核意见。
4. **诚信要求**：弄虚作假取消认定资格，5 年内不得再享人才政策。

## 与 GitHub 官方统计的对应关系

| GitHub 展示 | 通常计入贡献的操作 | 不计入 |
|-------------|-------------------|--------|
| Contributions in the last year | 默认分支 commit（邮箱已验证且关联账号） | 未关联邮箱的 commit |
| | 开 Issue / PR / Review | 非默认分支 commit |
| | 参与 Discussions | 空 commit、仅改 README 的机械刷量 |
| 仓库 Fork 数 | 其他用户 fork **你拥有的仓库** | 你 fork 别人的仓库 |

## 若口径与预期不符的备选

- **自然年已来不及**：评估是否可延至下一认定窗口，或改走 Gitee / 其他创新贡献标准（自媒体 IP 等）。
- **单仓库 200 Fork**：加大 flagship 仓库传播，见 [COMMUNITY_LAUNCH.md](COMMUNITY_LAUNCH.md)。
- **细则未发布**：关注 i深圳 通知；9 月前每周查一次是否公布 GitHub/Gitee 量化标准。
